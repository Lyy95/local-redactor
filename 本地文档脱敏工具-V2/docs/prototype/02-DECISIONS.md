| D-012 | 正式 EXE 的“选择文件”必须调用 Windows 原生 DOCX 文件选择器；桥接不可用时必须显示阻断错误，不得回退到虚构样例选择器 |
| D-013 | 任务历史必须在启动时从本地加密存储自动读取，并通过“完成任务 → 关闭 EXE → 重新打开”验收 |
| D-014 | 2026-08-31 用户黑盒验收发现启动步骤、文件选择和历史均不符合要求；Gate 2 从“完成”撤回为“验收失败，待修复” |
| D-015 | V2 离线识别组件优先复用旧版和本机已有资产，不重新下载；打包时生成资产清单，冻结 EXE 启动时按 SHA-256 失败关闭校验 |
| D-016 | 真实 DOCX 的第 3 步必须通过结构化预览适配复用 UX 原型正文 DOM：命中项在正文内高亮，建议卡锚定正文命中位置；禁止用整段纯文本加独立“本机识别结果”列表替代原型布局 |
