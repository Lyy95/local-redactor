# V2 本地桌面应用重构 Module Brief

## 目标

完全按照 `D:\AI\GPT项目\通用\本地文档脱敏工具-UX原型` 已确认的页面、组件、文案、状态和交互，重建一个可脱网运行的 Windows 本地文档脱敏桌面应用；旧版程序继续保留并可独立运行。

## 第一阶段范围

- 单文件 DOCX。
- 选择、检查、复核、生成、历史五个工作面。
- 复用旧版检测/转换/报告/映射能力。
- 新建原生桌面 UI 和任务状态桥接层。
- 原型逐屏、逐状态、逐操作对齐，不另做一套 V2 视觉方案。

## 后续阶段

规则库、XLSX、文件夹队列、图片/OCR、失败重试和完整历史操作在第一闭环验收后分阶段迁移。

## 非目标

本阶段不做网页交付、不做云端能力、不改旧版、不新增视觉方案、不做部署、不迁移全部功能。

## 保护面

旧版目录、UX 原型目录、旧版输出规则、安全边界和已有自动化测试均受保护。

## 完成标准

单个测试 DOCX 能从选择走到分离输出；用户可返回上一步；第 4 步可进入；失败路径可解释；旧版测试不回归。

## 功能范围索引

正式应用功能、Gate 2 闭环、Gate 3 规则库功能及待确认规则统一见 `06-FUNCTION_LIST.md`。
