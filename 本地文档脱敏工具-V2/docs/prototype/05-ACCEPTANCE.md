# V2 Gate 2 验收条件（单文件 DOCX）

## 0. 验收结论规则

- 验收对象必须是当次交付的打包 EXE/onedir，不是 Vite 页面、Python 直跑源码或 UX 原型。
- P0 硬门槛 A–D 任一失败，Gate 2 直接判定不通过；不得用单元测试、桥接测试、构建成功或截图抵消。
- 验收必须记录 EXE 路径、版本/SHA-256、测试 DOCX 名称、步骤结果和失败证据。
- 当前结论（2026-08-31）：**验收失败，不可标记 Gate 2 完成**。

## A. P0 冷启动必须停在第 1 步

Given：用正常入口启动打包 EXE。  
When：主窗口首次可操作。  
Then：

- [ ] 工作区显示“第 1 步 / 选文件”和“新建任务”。
- [ ] 没有选择文件时，不得出现第 2、3、4 步工作区。
- [ ] 不得显示“虚构项目方案.docx”、`initialFindings`、虚构待办或虚构当前任务。
- [ ] 关闭并重新打开 EXE，工作区仍从第 1 步开始；不自动跳入上次第 3 步。

失败条件：启动后直接出现第 3 步或虚构任务，即为 P0。

## B. P0 第 1 步必须能选择真实 DOCX

Given：打包 EXE 正常启动且停在第 1 步。  
When：点击“选择单个文件/选择文件”。  
Then：

- [ ] 3 秒内弹出 Windows 原生文件选择器，筛选条件为 `*.docx`。
- [ ] 点击取消后仍留在第 1 步，不创建任务。
- [ ] 选中有效 DOCX 后显示真实文件名、DOCX 类型、大小和“原文件只读”。
- [ ] 未选文件时“开始检查”不可进入第 2 步；选择有效 DOCX 并确认边界后才可进入。
- [ ] 选择非 DOCX、损坏、加密、宏或危险 OOXML 时显示明确阻断原因。
- [ ] QWebChannel/本地桥接未就绪时，显示“本地能力未就绪，请重启”类阻断错误；不得打开虚构样例弹窗。

失败条件：按钮无响应、打开虚构选择器或无法将真实 DOCX 带入第 2 步，即为 P0。

## C. P0 单 DOCX 必须完成真实四步闭环

- [ ] 第 2 步显示真实检查进度，成功后进入第 3 步；失败显示原因和重试入口。
- [ ] 第 3 步的原文、命中项、待处理数均来自选中 DOCX，不是原型数据。
- [ ] 真实 DOCX 按段落/标题结构展示；文字命中项在正文对应位置高亮，建议卡锚定所选正文命中项，不得退化为整段纯文本加独立识别列表。
- [ ] `采用建议 / 修改 / 保留原文 / 删除` 四个动作分别用真实命中项验收，列表、待处理数和预览同步。
- [ ] 手工添加脱敏内容后，右侧列表、待处理数和文档预览同步。
- [ ] 返回第 1/2/3 步再继续，已做决定不丢失。
- [ ] 待处理数不为 0 时不能生成；清零后可进入第 4 步。
- [ ] 第 4 步真实生成 `AI交付/AI分析副本.docx`、`本地保管/脱敏映射表.xlsx`、`本地保管/脱敏检查报告.html`。
- [ ] 原 DOCX 的 SHA-256 前后一致；AI 交付目录不含映射表；生成失败不显示伪成功。

## D. P0 任务历史必须跨进程保留

Given：在打包 EXE 中至少完成 1 个 DOCX 任务，并另造 1 个失败或未完成任务。  
When：正常关闭 EXE，再次双击同一个 EXE。  
Then：

- [ ] 启动后自动读取本地历史，无需先新建任务。
- [ ] 历史列表仍显示文件名、时间、成功/失败/未完成状态、处理数和结果可用性。
- [ ] 完成任务可查看本地结果；失败任务可重试；未完成任务可继续。
- [ ] 历史中不存原文、可逆映射、完整本机路径或密码。
- [ ] 真实历史为空时显示空状态；不得显示 `initialHistory` 虚构数据。

失败条件：完成任务后重启 EXE，历史消失或变成虚构数据，即为 P0。

## E. 桌面、离线与视觉回归

- [ ] 断网后可启动、选文件、检查、复核、生成和查看历史，不发起 HTTP/HTTPS 请求。
- [ ] 便携目录包含 RapidOCR 的 3 个 ONNX 模型、ONNX Runtime、`zh_core_web_sm` 和 OpenCV 人脸候选资产，不依赖运行时下载。
- [ ] EXE 启动时必须校验 `model-manifest.json`；清单、模型或哈希缺失时阻断启动，不能降级为少检。
- [ ] 构建和运行验收过程不访问 GitHub、PyPI 或模型下载服务。
- [ ] 在无 Python、无 Node 的 Windows 10/11 x64 干净环境完成 A–D。
- [ ] 1536×1024、1440×900、1280×720 下对齐 UX 原型，无遮挡、溢出和断裂路径。
- [ ] 侧栏、Logo、顶部展开按钮、第 3 步建议卡和第 4 步输出卡保持已确认样式。
- [ ] 旧版测试通过，旧版和 UX 原型保护哈希不变。

## F. 必须留存的验收证据

- [ ] 一段从双击 EXE 到第 1 步选文件、完成四步、关闭重开后查看历史的连续录屏或等价可重放操作记录。
- [ ] 当次打包 EXE 和 ZIP 的 SHA-256。
- [ ] 真实测试 DOCX 的原件/输出文件哈希及目录隔离检查结果。
- [ ] 当次打包对应的 V2 测试、旧版回归、harness 结果。
