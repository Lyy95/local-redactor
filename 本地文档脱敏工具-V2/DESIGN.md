# 本地文档脱敏工具 V2 Design Baseline

## 设计来源

1. `D:\AI\GPT项目\通用\本地文档脱敏工具-UX原型`，V2 界面的唯一设计源。
2. 当前用户关于本地桌面应用和脱网运行的明确要求。
3. 旧版已验证的安全文案和处理边界。

## 完全对齐规则

本文件不是重新设计一套界面，而是把 UX 原型的已确认结果转为正式桌面应用约束。V2 必须保持原型的：

- 页面结构、侧栏结构和展开/收起行为；
- 组件位置、宽度、间距、字号、颜色、边框和状态样式；
- 页面标题、按钮文案、提示文案和错误反馈；
- 四步流程、复核动作、规则依据、手工添加和返回路径；
- 任务、历史、规则和生成结果的可见字段与状态。

允许变化的只有操作系统窗口边框、原生文件选择器和打包入口等桌面平台外壳。工作区内部不得做视觉或交互再解释。

## 桌面应用约束

- 目标平台：Windows 10/11 x64。
- 交付形态：便携 ZIP 或 EXE，双击启动，不要求浏览器和网络。
- 目标窗口：1536×1024；正常支持 1440×900；最低支持 1280×720。
- 离线状态、原文件只读、结果目录和“严禁上传”必须在主界面持续可见。

## 固定流程

`选文件 → 自动检查 → 确认处理 → 生成文件`

步骤 2–4 提供明确的返回上一步动作，并保留当前任务、复核决定和待处理数量。

## 布局与交互

- 白底、薄荷绿、深绿色，低密度、非技术化中文。
- 任务/规则使用真实的内嵌侧栏；展开推动内容，不使用浮窗、遮罩、吸附或悬停展开。
- 收起状态的侧栏展开按钮绝对定位在导航右上角、完整收在分隔线内侧；按钮无背景、无边框、无阴影，不占用单独的纵向布局；Logo 缩小并略向左收，避免与按钮挤压。
- 收起侧栏约 104px，展开总宽约 420px；模块切换不自动收起。
- 第 3 步默认显示文档、右侧待处理列表和逐项操作。
- 建议卡锚定在选中原文附近，保持 `采用建议 / 修改 / 保留原文 / 删除`，不得遮挡原文。
- 支持“添加脱敏内容”，加入同一待处理数量、列表和生成逻辑。
- 保留“一键采用全部建议并继续”作为批量普通路径，不再增加重复批量按钮。
- 轻量反馈位于顶部中央；规则依据默认是紧凑的可展开提示。

## 输出呈现

- AI 交付：`<原文件名>-脱敏稿.<扩展名>`。
- 本地保管：`脱敏映射表.xlsx`、`脱敏检查报告.html`。
- 完成文案：`技术检查已完成，仍需按单位制度确认是否可外发。`
- 禁止使用“已脱密”“可安全上传”“绝对安全”“100%安全”等表述。
