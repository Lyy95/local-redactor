# 本地文档脱敏工具

面向 Windows 办公用户的离线 Word/Excel AI 分析副本生成器。

它在本机扫描 `.docx` / `.xlsx` 的文字、单元格、图片和隐藏 Office 对象，经用户确认后，从空白容器重建同格式副本，并生成一份密码加密的 XLSX 脱敏映射表。

> 本工具提供技术识别、人工确认、纯净重建和导出复扫。技术检查完成不等于文件已脱密，也不代表可安全上传或已获准外发。

## 每次任务的输出

```text
脱敏结果_YYYYMMDD_HHMMSS/
├─ AI交付/
│  └─ AI分析副本.docx  或  .xlsx
└─ 本地保管/
   ├─ 脱敏映射表.xlsx
   └─ 脱敏检查报告.html
```

- `AI交付` 中只有重建后的分析副本。
- 映射表使用 Office Agile Encryption 密码加密，严禁上传。
- 报告不含原始敏感值、替代值或密码。
- 原文件只读，不会原地覆盖、移动或重命名。

## 首版范围

- 支持 `.docx`、`.xlsx`。
- 本地规则和中文实体候选覆盖姓名、证件、联系方式、地址、车牌、账号、单位、部门、项目、系统、地点、时间、金额、编号和网络标识。
- 图片运行本地 OCR、二维码、人脸、印章和签名候选检测；每张图片无论命中与否都必须由用户决定。
- 图片遮挡区域会写入与正文一致的代号或编号，并在文档中生成可见说明。
- 枚举属性、修订、批注、隐藏内容、页眉页脚、超链接、附件、嵌入对象、外部连接及组合识别风险。
- 默认“保留可读性”，也可选择“隐藏更多细节”。
- “采用全部普通建议”只处理把握较高的普通文字和单元格；图片、低把握内容、组合风险、附件和嵌入对象仍须逐项确认。
- 必需的文字实体组件异常时阻断导出；图片识别组件异常时，只允许遮住整张图片或删除整张图片。

旧式 Office、宏格式、密码/IRM 文件、PDF、PPT、批量任务和自动还原不在首版范围内。

## 本机规则库

- 固定替换：沉淀明确的对应关系，例如 `公安 → GA`、`网警 → WJ`。
- 判断标准：沉淀一类内容的处理方法，例如 `530网 → 5**网`；`jz`、`qb` 等不透明代号只按明确条件处理，不擅自推断含义。
- 强制规则命中后必须改为代号或删除，不能保留原文。
- 在确认页面修改代号并点击“以后都这样处理”，可直接保存为固定替换；保存后当前任务会要求重新检查。
- 支持新增、编辑、停用、删除，以及 CSV/XLSX 批量导入和空白模板导出。
- 导入内容与现有规则冲突时，必须选择“保留现有规则”“采用导入规则”或“取消导入”，不会静默覆盖。
- 规则库使用 Windows 当前用户加密能力保存；程序重启后仍在，但只应在受控电脑使用。
- 每次任务冻结开始检查时的规则版本。处理中修改规则后，必须重新检查当前文件。

## 开发运行

```powershell
.\.venv\Scripts\python.exe -m local_redactor.app
```

虚构界面演示：

```powershell
.\.venv\Scripts\python.exe -m local_redactor.app --demo-docx
```

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
.\.venv\Scripts\python.exe -m ruff check --no-cache src tests scripts
.\.venv\Scripts\python.exe scripts\verify_release.py
```

## 构建 Windows 绿色版

```powershell
.\.venv\Scripts\python.exe scripts\build_windows.py
```

输出：

```text
dist/
├─ 本地文档脱敏工具/
│  ├─ 本地文档脱敏工具.exe
│  ├─ 离线识别组件/
│  ├─ 使用说明.pdf
│  └─ 版本与校验.json
└─ 本地文档脱敏工具-Windows-x64.zip
```

构建会生成并嵌入离线模型 SHA-256 清单，随后以离屏模式启动最终 EXE 自检。冻结版启动时模型文件缺失或被修改会失败关闭。

更详细的范围、决策和验收证据见 [docs/prototype](docs/prototype)。
