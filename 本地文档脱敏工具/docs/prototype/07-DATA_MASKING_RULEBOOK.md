# 本地文档脱敏规则手册

## 一、适用范围

本手册适用于本机离线生成 Word、Excel AI 分析副本的静态脱敏流程。规则目标是在不保留完整敏感原值的前提下，尽量保留文档的角色、关系、结构、数量级和分析价值。

本工具不是数据库查询网关，不提供按用户、角色或时间段动态展示原文的白名单。需要核对时，只能在 `本地保管` 中使用脱敏映射表；该表含真实原值，不设置打开密码，也绝不得进入 `AI交付` 或上传外部系统。

## 二、规则分层和优先级

| 优先级 | 规则层 | 典型内容 | 生效原则 |
|---:|---|---|---|
| 1 | 当前任务人工决定 | 修改、删除、确认误报 | 仅影响当前规则快照；强制规则不得保留原文 |
| 2 | 用户强制规则 | 用户确认必须替换的词、格式和判断标准 | 命中后必须替换或删除 |
| 3 | 本机固定词规则 | `公安→GA`、警种和部门大写首字母 | 最长词优先；冲突时使用更完整首字母组合 |
| 4 | 内置敏感类型规则 | 姓名、证件、联系方式、账号、网络信息等 | 结构化校验优先于宽泛文本识别 |
| 5 | 本地模型候选 | 单位、地点、项目、系统、图片文字等 | 作为候选进入人工确认，不直接视为安全结论 |

同一位置出现多条规则时，优先采用范围更准确、校验更强、级别更高的规则。局部命中不能吞掉更大范围的敏感候选。

## 三、默认字段规则

| 规则 ID | 数据类型 | 识别与校验 | 默认处理 | 示例形式 | 是否强制 |
|---|---|---|---|---|---:|
| PII-NAME-01 | 中文姓名 | 字段标签、本地实体识别；识别常见复姓 | 保留姓氏，其余为 `*` | `张*`、`欧阳**` | 是 |
| PII-MOBILE-01 | 手机号 | 中国大陆手机号边界和号段格式 | 保留前三后四 | `138****5678` | 是 |
| PII-LANDLINE-01 | 固定电话 | 带区号的 7–8 位座机格式 | 仅保留后四位 | `****8888` | 是 |
| PII-ID-01 | 身份证号 | 18 位、出生日期和校验码 | 保留前六后四 | `420101********1234` | 是 |
| PII-BANK-01 | 银行卡号 | 明确银行卡标签；无标签时要求 16–19 位且通过 Luhn | 保留前六后四 | `622202******7890` | 是 |
| PII-EMAIL-01 | 电子邮箱 | 邮箱结构和边界 | 用户名前两位可见，其余为 `*`，域名保留 | `ab***@example.com` | 是 |
| PII-ADDRESS-01 | 详细地址 | 地址标签、行政区划和门牌结构 | 保留最低必要行政层级，删除门牌房间 | `某市某区` | 是 |
| PII-PLATE-01 | 车牌号 | 省份简称、号牌长度和字符范围 | 使用一致车辆代号并保留车辆类别 | `车辆甲（小型汽车）` | 是 |
| SECRET-PASSWORD-01 | 密码/口令/PIN | 仅在密码、口令、PIN 等明确标签后识别 | 删除，且不写入映射表 | `密码：Abc#1234 → 删除` | 是 |
| SECRET-TOKEN-01 | 密钥/令牌 | Token、API Key、AccessKey、SecretKey 等明确标签 | 删除，且不写入映射表 | `token: eyJ... → 删除` | 是 |
| NET-IP-01 | IP 地址 | IPv4/IPv6 解析校验并区分内外网 | 使用文档保留网段或模拟地址 | `203.0.113.x` | 是 |
| NET-DOMAIN-01 | 域名 | 域名结构、后缀和文件扩展名排除 | 使用一致模拟域名 | `org01.example.invalid` | 是 |
| NET-USER-01 | 用户名/账号 | 字段标签和受控格式 | 使用一致用户或账号代号 | `user01` | 是 |
| BIZ-ORG-01 | 单位/部门/项目/系统 | 本地模型、后缀规则、任务词和固定词规则 | 保留机构或业务类型，使用一致代号 | `某部门甲` | 是 |
| BIZ-MONEY-01 | 金额 | 数字、币种和单位 | 区间化，保留数量级 | `100万—150万元` | 是 |
| BIZ-TIME-01 | 时间 | 当前策略不生成候选 | 保留原文，不参与组合风险 | 原文不变 | 否 |
| VISUAL-01 | 图片中的人脸、结构化敏感信息、二维码和强制规则命中 | OCR、二维码和人脸候选；普通 OCR/照片不进入待办 | 像素改写、移除或安全重编码 | 不保留可移除遮罩 | 敏感命中是 |
| OBJECT-01 | 隐藏内容、批注、修订、脚注尾注、附件、外链和嵌入对象 | OOXML 全部部件和关系清点 | 默认自动删除；无法安全删除时阻断 | 不复制活动对象 | 是 |

## 四、处理方法选择

1. **分段掩码**：用于姓名、手机号、身份证、银行卡、邮箱和固定电话；保留业务所需的最少字符。
2. **一致代号**：用于人员关系以外的单位、部门、项目、系统、车辆和账号，保证同一实体跨正文、表格和图片 OCR 使用同一结果。
3. **泛化或区间化**：用于地址、地点和金额，保留分析所需层级或数量级。
4. **固定替换**：用于公安行业词和用户明确指定的长期代号。
5. **删除或阻断**：用于密码、密钥、令牌、无法安全重建的对象以及无法确认的高风险内容。密码不能因为显示为星号就被视为已安全存储。
6. **本地映射**：只用于本机核对还原，不替代 AI 分析副本中的实际脱敏；映射表不设密码，因此必须严格留在 `本地保管`。

不使用无密钥哈希处理低熵、可枚举的手机号或银行卡号；不把简单摘要误称为加密。

## 五、规则生命周期

- 每条规则必须有唯一名称、敏感类型、作用范围、启用状态、优先级和是否强制。
- 新规则保存前必须使用虚构样本预览脱敏效果。
- 规则修改后，在正在处理任务的已解析文字和 OCR 缓存上增量应用，然后用刷新后的唯一快照导出。
- 启用、停用、导入冲突和损坏恢复均不得静默覆盖。
- 导出前必须重新打开实际 DOCX/XLSX，对文字、数字、图片 OCR、二维码、关系、媒体字节和活动对象进行独立复扫。
- 日志只记录规则编号、类别、数量和结果状态，不记录原词、替换对、密码或完整路径。
